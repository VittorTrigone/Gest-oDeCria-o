# Diretrizes de Código Limpo e Reflexão Crítica

Antes de escrever, modificar, adicionar ou remover qualquer código neste projeto, você (a IA) DEVE fazer uma pausa e refletir silenciosamente sobre as seguintes perguntas:

1. **Necessidade:** Este código é estritamente necessário para o objetivo atual?
2. **Utilidade:** O que exatamente esse código faz? Ele está sendo útil e resolvendo o problema da forma mais eficiente?
3. **Minimalismo (YAGNI):** Eu realmente preciso adicionar isso agora? Existe uma forma mais simples ou nativa de resolver sem inflar a base de código?
4. **Segurança e Impacto:** Se eu remover ou alterar isso, algo vai quebrar? Quais são os efeitos colaterais dessa mudança no restante do sistema?
5. **Legibilidade:** Este código está limpo, polido, organizado e fácil de ser lido por outros desenvolvedores?

**Regra de Ouro:** Apenas implemente o código se ele passar por esse "filtro". Se algo puder ser simplificado ou removido sem perda de funcionalidade (KISS), faça isso. Seu objetivo é manter o projeto profissional, enxuto e escalável.
